# PukiWiki 記法リファレンス

このドキュメントは PukiWiki の整形ルールを定義します。Markdown から PukiWiki 形式への変換時に参照してください。

## ブロック要素

### 段落

```
インライン要素
```

または

```
~ インライン要素
```

行頭書式の文字 (~、-、+、:、>、|、#、//) を通常の文字として段落の先頭に書きたい場合は、行頭に ~ を記述します。

### 見出し

```
* インライン要素       # レベル1
** インライン要素      # レベル2
*** インライン要素     # レベル3
```

### 目次

```
#contents
```

### リスト構造

**番号なしリスト:**
```
- インライン要素       # レベル1
-- インライン要素      # レベル2
--- インライン要素     # レベル3
```

**番号付きリスト:**
```
+ インライン要素       # レベル1
++ インライン要素      # レベル2
+++ インライン要素     # レベル3
```

### 引用文

```
> インライン要素       # レベル1
>> インライン要素      # レベル2
>>> インライン要素     # レベル3
```

### 定義リスト

```
: 定義語 | 説明文
:: 定義語 | 説明文     # レベル2
::: 定義語 | 説明文    # レベル3
```

### 整形済みテキスト（コードブロック）

行頭に半角空白を付けます：

```
 整形済みテキスト
 行の自動折り返しは行われない
```

### 水平線

```
---------------------------------------------
```

または

```
#hr
```

### 表組み

**基本形式:**
```
| インライン要素 | インライン要素 |
```

**セル内の書式指定:**
- `LEFT:` - 左寄せ（デフォルト）
- `CENTER:` - センタリング
- `RIGHT:` - 右寄せ
- `BGCOLOR(色):` - 背景色
- `COLOR(色):` - 文字色
- `SIZE(サイズ):` - 文字サイズ（px）

**特殊セル:**
- `~インライン要素` - ヘッダセル（th）
- `>` - 右のセルと結合（colspan）
- `~` - 上のセルと結合（rowspan）

**行の種類:**
- 行末に `h` - ヘッダ行（thead）
- 行末に `f` - フッタ行（tfoot）
- 行末に `c` - 書式指定行

**CSV形式の表組み:**
```
,データ,データ,…
```

### 左寄せ・センタリング・右寄せ

```
LEFT:インライン要素
CENTER:インライン要素
RIGHT:インライン要素
```

### 行間開け

```
#br
```

### 添付ファイル・画像の貼り付け

```
#ref(添付ファイル名)
#ref(ファイルのURL)
```

パラメタ:
- `left`, `center`, `right` - 表示位置
- `wrap`, `nowrap` - 枠で囲むか
- `around` - テキストの回り込み
- `nolink` - リンクを張らない

### コメント行

```
// コメント
```

## インライン要素

### 改行

**行末改行:**
```
インライン要素~
```

**行中改行:**
```
&br;
```

### 強調・斜体

```
''インライン要素''   # 強調
'''インライン要素'''  # 斜体
```

### 文字サイズ

```
&size(サイズ){インライン要素};
```

### 文字色

```
&color(文字色,背景色){インライン要素};
&color(文字色){インライン要素};
```

色の指定:
- 色キーワード
- #16進数6桁
- #16進数3桁

### 取消線

```
%%インライン要素%%
```

### 注釈

```
((インライン要素))
```

### リンク

**ページ名:**
```
[[ページ名]]
[[ページ名#アンカー名]]
```

**URL:**
```
http://www.example.com/
https://www.example.com/
[[リンク名:URL]]
```

**エイリアス:**
```
[[エイリアス名>ページ名]]
[[エイリアス名>ページ名#アンカー名]]
[[エイリアス名>#アンカー名]]
[[エイリアス名>URL]]
[[エイリアス名:URL]]
```

**InterWiki:**
```
[[InterWikiName:ページ名]]
[[InterWikiName:ページ名#アンカー名]]
```

### アンカーの設定

```
&aname(アンカー名);
&aname(アンカー名){インライン要素};
```

### ルビ構造

```
&ruby(ルビ){インライン要素};
```

### 添付ファイル・画像の貼り付け（インライン）

```
&ref(添付ファイル名);
&ref(ファイルのURL);
```

パラメタ:
- `nolink` - リンクを張らない
- `代替文字列` - 表示文字列

### 日時置換文字

```
&date;      # 更新時の日付
&time;      # 更新時の時刻
&now;       # 更新時の日時
&_date;     # 表示時の日付
&_time;     # 表示時の時刻
&_now;      # 表示時の日時
&lastmod;   # ページの最終更新日時
```

### タブコード

```
&t;
```

## 変換マッピング

### Markdown → PukiWiki 主要な対応表

| Markdown | PukiWiki | 説明 |
|----------|----------|------|
| `# 見出し1` | `* 見出し1` | 見出しレベル1 |
| `## 見出し2` | `** 見出し2` | 見出しレベル2 |
| `### 見出し3` | `*** 見出し3` | 見出しレベル3 |
| `- リスト` | `- リスト` | 番号なしリスト |
| `1. リスト` | `+ リスト` | 番号付きリスト |
| `> 引用` | `> 引用` | 引用文 |
| ` ```code``` ` | ` コード` | 整形済みテキスト（行頭に空白） |
| `**太字**` | `''太字''` | 強調 |
| `*斜体*` | `'''斜体'''` | 斜体 |
| `~~取消線~~` | `%%取消線%%` | 取消線 |
| `[リンク](URL)` | `[[リンク:URL]]` | リンク |
| `![画像](URL)` | `#ref(URL)` | 画像 |
| `---` | `----` | 水平線 |
| テーブル | 表組み | 表（形式変換必要） |

### 特殊な変換

**コードブロック:**
````markdown
```language
code
```
````

→

```pukiwiki
 code
```

**テーブル:**
```markdown
| ヘッダ1 | ヘッダ2 |
|---------|---------|
| データ1 | データ2 |
```

→

```pukiwiki
|~ヘッダ1|~ヘッダ2|h
|データ1|データ2|
```

**リンク:**
- `[テキスト](URL)` → `[[テキスト:URL]]`
- `[テキスト](ページ)` → `[[テキスト>ページ]]`

**画像:**
- `![alt](URL)` → `#ref(URL,nolink,alt)`

**改行:**
- Markdown の行末スペース2つ → `~`
- 明示的な `<br>` → `&br;`

## 注意事項

### frontmatter の扱い

MDX ファイルの frontmatter（YAML ヘッダ）は PukiWiki には存在しないため、以下のように変換します：

```yaml
---
title: タイトル
date: 2024-01-01
tags: [tag1, tag2]
---
```

→

```pukiwiki
// title: タイトル
// date: 2024-01-01
// tags: tag1, tag2

* タイトル
```

または、定義リストとして表現：

```pukiwiki
:title|タイトル
:date|2024-01-01
:tags|tag1, tag2
```

### エスケープが必要な文字

PukiWiki で特別な意味を持つ文字を通常の文字として使用する場合：
- 行頭の `~`, `-`, `+`, `:`, `>`, `|`, `#`, `//` → 行頭に `~` を付ける
- インライン要素内の特殊文字は文脈に応じてエスケープ

### ネスト構造の制限

- リスト構造: 3段階まで (`-`, `--`, `---`)
- 引用文: 3段階まで (`>`, `>>`, `>>>`)
- 定義リスト: 3段階まで (`:`, `::`, `:::`)
