# ナビゲーション（E）

現在地・戻り道・メニューの順序・遷移の向き。メニュー項目の文言は `text.md` の A-2 にある。

## E-1 今どこにいて、どこへ行けるかを示す

- 階層のある画面にはパンくずを置く。
- メニューやタブは、今いる項目をハイライトする（ハイライトの仕方は B-5）。
- 階層は3段程度に抑える。深くなるほど迷う。

## E-2 いつでも抜けられる出口を用意する

- どの画面からもホームへ戻れるようにする。
- モーダルやパネルは、閉じるボタンと ESC キーで閉じられるようにする。
- 長いフォームは途中で止められるようにする（下書きの保存・自動保存・続きから再開）。

## E-3 メニューの項目の位置を変えない

- ユーザーは項目を位置で覚える。使った回数や最近使った順で並べ替えない。カテゴリなど決まった順に並べる。
- ログインの前後などで項目が増えるときは、既にある項目の位置を保ち、新しい項目は後ろに足す。

## E-4 選んだ内容は、下か右に出す

- 上で選んだものの内容は下に、左で選んだものの内容は右に表示する。読む順と同じ向きにする。
- 親から子への関係も、上から下、左から右に並べる。

## E-5 左を戻る、右を進むにする

- 戻る（過去）を左、進む（未来）を右に置く。矢印の向きも合わせる。
- 「次へ」で画面が切り替わるときは、次の画面が右から入ってくる向きに動かす。
- ボタンの並びは `components.md` の B-4 と同じ向きになる。

## E-6 モバイルでは、一度に見せる量を絞って階層に分ける

- 条件: モバイル幅のとき。
- 1画面に全てを詰めず、要るものだけを見せ、詳細は次の階層に送る。
- 長い一覧は、大分類 → 中分類 → 詳細と段階に分ける。
- 横に広い表は、そのまま縮めず、カードに組み替える。
