# 入力フォーム（C）

入力項目の持ち方・部品の選び方・入力の受け付け方。項目の並べ方は `layout.md` の D-3 にある。

## C-1 ほかの入力から求まる値を入力させない

- 2つの入力が食い違う可能性があるなら、片方だけを入力させ、もう片方は計算して表示する。
- 例:
  - 生年月日と年齢 → 生年月日だけ入力させ、年齢は計算する
  - 明細と合計 → 明細だけ入力させ、合計は計算する
  - 開始日・終了日・期間 → 開始日と終了日から期間を計算する

## C-2 妥当な値を初期値にする

- 多くの人が選ぶ値を、最初から選んでおく。変えたい人だけが変えればよい。
- 例:
  - 配送方法・日時・包装を全て「選択してください」にする → 通常配送・最短・包装なしを初期値にする
  - 国の選択がアルファベット順の先頭 → ブラウザのロケールや位置から推測した国にする
  - 予約日時が空 → 今の日時を初期値にする

## C-3 入力できる値が決まっているなら、選ばせる部品にする

- 決まった選択肢から選ぶ: ドロップダウン・ラジオボタン
- 範囲のある数: ＋／－ボタン・スライダー
- 日付: 日付ピッカー
- 自由入力にすると、存在しない値・範囲外の値・書式の誤りが入る。

## C-4 選択肢が少なければ、全て並べて見せる

- 選択肢が3〜4つで場所に余裕があれば、ドロップダウンに隠さず、ラジオボタンやカードで並べる。全てが一度に見え、1回で選べる。
- 1つだけ選ぶなら ○、いくつでも選べるなら ☐ の形にし、選び方を見た目で伝える。
- 選択肢に説明（サイズの目安など）を添えられる。

## C-5 設定値ではなく、得られる結果で選ばせる

- 数値のパラメーターを入力させても、ユーザーには結果が想像できない。結果の名前で選ばせ、数値は補足に書く。
- 例:
  - 幅（px）と品質（1〜100）→「小 / 中 / 大」（それぞれのサイズの目安を添える）
  - 「幅: 1920px」→「HD / Full HD / 4K」
  - 文字の大きさ「12pt」→「本文 / 見出し / タイトル」

## C-6 書式のある値は、入力欄を書式に合わせて分ける

- 区切りのある値は区切りごとに欄を分け、埋まったら次の欄へフォーカスを移す。
- 例:
  - 電話番号 → 区切りごとの欄
  - カード番号16桁 → 4桁×4欄
  - 住所 → 都道府県（ドロップダウン）・市区町村・番地の欄

## C-7 書式の揺れはシステムが吸収する

- 全角／半角、ひらがな／カタカナ、ハイフンの有無、大文字／小文字の違いでエラーにしない。受け取ってから正規化する。
- 例:
  - 郵便番号を全角で入力 → 半角に直して受け付ける
  - 「09012345678」と「090-1234-5678」→ どちらも受け付け、表示は整える
  - 「User@Example.com」→ 小文字にして受け付ける

## C-8 入力の途中で候補を出す

- 途中まで入力したら、入れようとしている値や過去の入力を候補として出す。
- 候補は5〜10件に絞る。多すぎると探す手間が戻ってくる。続きは入力で絞り込ませる。
