# 情報の表示（H）

状態・数値・日時・アイコン・一覧の見せ方。

## H-1 オブジェクトは自分の状態を常に見せる

- 一覧の各項目に、開かなくても状態が分かる表示を付け、変化したらすぐ反映する。
- 例:
  - タスク → 完了・進行中・未着手を一覧で示し、全体の進み具合も出す
  - メール → 未読を太字や印で示す
  - 商品 → 「在庫あり」「残り3点」「在庫切れ」を示す

## H-2 データではなく、その意味を見せる

- ユーザーが知りたいのは数値そのものより、それが何を意味するかである。
- 例:
  - 使用バイト数 → 「残り30%」とプログレスバー、残りが少ないときは注意も出す
  - 「2025-01-10 14:32:45」→ 「3分前」「昨日」（正確な日時はホバーなどで見せる）
  - 「1073741824 bytes」→ 「1 GB」と読みやすい単位にする

## H-3 何であるかを見た目で示し、文字で補う

- 種類や状態はアイコンで一目で分かるようにし、文字で説明を添える（ファイルの種類のアイコン＋「PDF・2.4MB」）。
- アイコンだけのボタンには、ホバーで出る説明か、ラベルを付ける。
- エラーなどの状態は、文字だけでなく、アイコンと色でも示す（色だけにしない。H-6）。

## H-4 続きがあるなら、続きがありそうに見せる

- 画面の下端でちょうどコンテンツが途切れると、スクロールできると気づかれない。
- 下端で項目や画像が途中で切れて見える高さにするか、次の節の見出しが少し見えるようにする。

## H-5 選択肢を、選んだ結果の見本で見せる

- 色は色見本で、フォントはそのフォントで書いた見本で、大きさは実際の大きさで並べる。名前の文字だけで並べない。

## H-6 色が無くても伝わるようにする

- 色の違いだけで区別しない。アイコン・形・文字・線の種類（実線／破線／点線）を併せて使う。
- 例:
  - 成功／エラーを緑と赤だけで示す → アイコンとラベルを付ける
  - グラフの系列を色だけで分ける → 線の種類も変える
  - 必須を赤い「*」だけで示す → 「（必須）」と書く
- グレースケールで表示して、区別が残るかを確かめる。
