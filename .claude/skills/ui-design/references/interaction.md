# 操作と動き（F）

ドラッグ・ジェスチャ・アニメーション・反応の速さ・処理中の操作。

## F-1 対象を直接動かせるようにする

- 並べ替え・移動はドラッグ＆ドロップで、大きさの変更は角をドラッグして行えるようにする。「上へ」「下へ」ボタンや数値の入力だけにしない。
- ドラッグの間は、指やマウスの動きに合わせて表示を更新し続ける。
- キーボードでも同じ操作ができる手段を残す。

## F-2 広い範囲の変化にはアニメーションを付ける

- パネルの開閉・タブの切り替え・モーダルの表示のように広い範囲が変わるときは、0.1〜0.5秒のトランジションを付ける。何がどこへ変わったのかが目で追える。
- タブの切り替えは、タブの並びの向きにスライドさせる。

## F-3 アニメーションは行きと帰りの両方に付ける

- 開くときに付けたら、閉じるときにも付ける。
- 行きと帰りを同じ速さにする。

## F-4 操作には0.1秒以内に反応する

- 押した・乗せた瞬間に、見た目を変えて受け付けたことを示す。0.1秒を超えると、押せたかどうか分からなくなる。
- 処理に時間がかかるときは、まず受け付けたことを示してから処理する。
- 10秒以上かかる処理には、進み具合と残り時間を表示する。

## F-5 ジェスチャには、対象が指に付いてくるように反応させる

- スワイプ・ピンチ・回転は、指の動きに合わせて対象をリアルタイムに動かす。動きが終わってから結果だけを出さない。
- スワイプで削除などを確定するときは、指を離したときに確定し、途中で戻せば取り消せるようにする。

## F-6 処理中も UI をロックしない

- 数秒以上画面を操作できなくすると、ユーザーは操作の主導権を失ったと感じる。
- 処理中もキャンセルと他の操作をできるようにする。保存中に別の画面へ移れるようにする。
- ダイアログとモーダルの使い分けは、SKILL.md の規則3に従う。
