# 単一のコンポーネント（B）

ボタン・リンク・選択部品・トグルなど、1つの部品の見せ方と大きさ。

## B-1 押せるものは押せそうに、押せないものは押せなさそうに見せる

- ボタンは形・色・影で、周りの装飾と見分けられるようにする。
- 文中のリンクは、色と下線で本文と見分けられるようにする。
- 押せない状態（無効）は、薄い色にし、カーソルも変える。ただ灰色にするだけでは、他の灰色の要素と区別できない。

## B-2 1つを選ぶならラジオボタン、オン／オフならチェックボックス

- A か B かを選ぶ: ラジオボタン
- 真か偽か（する／しない）: チェックボックス
- いくつでも選べる: チェックボックスを並べる
- 選択肢が多い（目安は10個以上）: ドロップダウン。少ないときは C-4 に従って展開して見せる

## B-3 状態の表示と、押したときの操作を分ける

- 1つのボタンでオン／オフを切り替えると、ラベルが「今の状態」なのか「押すとそうなる」のかが分からない。
- 切り替えはスイッチにし、今の状態をスイッチの位置とラベルで示す。
- ボタンで切り替えるなら、今の状態（「再生中」）と操作（「停止」）を別々に表示する。
- アイコンだけで状態を示すときは、文字で補う（「お気に入り登録済み」）。

## B-4 否定のボタンを左、肯定のボタンを右に置く

- Web では、右を肯定（保存・次へ）、左を否定（キャンセル・戻る）にする。E-5 の「左が戻る、右が進む」と同じ向き。
- 主な操作のボタンを目立つ色にし、キャンセルは控えめにする。
- 対になるボタンは隣に並べる。画面の両端に離さない。

## B-5 ハイライトは、変える要素を1つにする

- ホバー・選択中・現在地を示すときは、背景色・左端の線など1つだけを変える。
- 色・大きさ・太さ・影を一度に変えると、別の種類の部品に見える。

## B-6 タップする要素は7mm 四方以上にする

- 条件: モバイル幅のとき。
- ボタン・アイコン・チェックボックスを7〜10mm 四方以上にする。アイコンが小さいときは、周りの余白を含めて押せる範囲を広げる。
- 隣り合う要素の間に余白を空け、隣を押し間違えないようにする。

## B-7 押せる範囲を見た目より広げる

- リンクは文字だけでなく、行やカード全体を押せるようにする。
- チェックボックスとラジオボタンは、ラベルを押しても選べるようにする。
- 一覧の行は、行全体を押して選べるようにする。
