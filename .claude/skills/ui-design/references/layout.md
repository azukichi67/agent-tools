# 配置（D）

要素のまとめ方・順序・位置・色とフォントの数・揃え。

## D-1 近さ・似た見た目・囲みで、まとまりを示す

- 関係する要素は近くに置き、関係しない要素との間は広く空ける。
- 同じ働きの部品は、同じ色と形にする。
- まとまりはカードや枠線で囲み、どこからどこまでが1つのまとまりかを見せる。
- 例: 設定項目を1列に並べる →「アカウント」「表示」「通知」のまとまりに分ける

## D-2 ツールは操作する対象の近くに置く

- 書式のツールは選んだ文字のそば、メニューは押した場所に出す。
- 対象から離れた場所にツールを置くと、視線が往復し、結果をその場で確かめられない。

## D-3 入力の項目は、身近で簡単なものから並べる

- 項目をユーザーにとって意味のあるまとまり（お客様情報・配送情報・お支払い）に分ける。
- 名前のような身近で簡単な項目を先に、支払いのような複雑な項目を後にする。
- 必須の項目を先に、任意の項目（備考など）を後にする。

## D-4 視線と操作の流れを作る

- D-1 のまとまりと D-3 の順序で、上から下へ視線が流れるようにする。
- 次に押すボタンを、主な操作として1つだけ目立たせる。進む向きは E-5 に従う。

## D-5 フィードバックは、操作した場所の近くに出す

- 入力のエラーは、画面の上部にまとめず、その入力欄のすぐ横に出す。
- 操作の結果は、ボタン自体の表示の変化か、すぐ近くの短い表示で示す。別の画面に遷移して知らせない。
- 完了を知らせるかどうかは、SKILL.md の規則2に従う。

## D-6 色とフォントの種類を絞る

- 色は役割（主な操作・注意・エラーなど）ごとに決めた少数に絞る。
- フォントは見出しと本文で揃える。
- 強調は太字だけにする。下線・斜体・太字を混ぜない（下線はリンクに使う。B-1）。

## D-7 グリッドに沿って揃える

- 要素をグリッドに沿って並べ、余白は決まった間隔の倍数にする。
- 揃えは左揃えを基本にする。左揃えと中央揃えを混ぜない。
